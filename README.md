# Sakinah Bloom

Sakinah Bloom is an Expo app for Swedish prayer times, built with Expo SDK 54, Expo Router, TypeScript, and NativeWind.

## Getting Started

Install dependencies:

```bash
npm install
```

Start the Expo development server:

```bash
npm start
```

Run the web preview:

```bash
npm run web
```

## Android

Regenerate the Android native project from Expo config:

```bash
npm run prebuild:android
```

Build and run Android directly:

```bash
npm run android
```

Regenerate Android and then build/run it:

```bash
npm run run:android
```

The Android prebuild is configured through `expo-build-properties` in `app.json`. It currently generates:

```properties
reactNativeArchitectures=arm64-v8a,x86_64
```

## Useful Commands

```bash
npm run generate:prayer-data
npm run test:prayer-data
npm run lint
```

## Project Notes

The app is client-only. Native folders are generated by Expo prebuild, so native build settings should be expressed in `app.json` or config plugins whenever possible.
